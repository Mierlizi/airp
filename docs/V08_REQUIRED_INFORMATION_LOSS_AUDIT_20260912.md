# AIRP v0.8 必要信息丢失审计

本审计修正了此前把模型答案准确率当作插件信息丢失率的问题。两者必须分开：信息丢失率检查AIRP是否把完成任务所需的证据删除或改错；答案准确率还会受到模型算术、注意力、提示格式和随机性的影响。

## 指标定义

每个合成任务预先登记两类必要信息单元：

1. 目标函数的精确`return`计算表达式，每题1个单元。
2. 每个必需依赖函数的名称与默认值，每个依赖1个单元。

必要信息丢失率 = AIRP输出中缺失或错误的必要信息单元数 / 全部必要信息单元数。代码规模直接用进入Baseline前的非空物理行数和`o200k_base`代码Token表示，不再用微型、中型等抽象名称作为主要尺度。

60个任务合计包含1,300个必要信息单元，AIRP丢失0个，观测必要信息丢失率为0%。作为干扰项植入的29,760个无关函数全部未进入AIRP证据，干扰函数移除率为100%。

这个结果解释了为什么“信息完整”和“模型答对”可以同时出现分歧：扩大模型实验中Baseline答对54/60、AIRP答对53/60，但证据审计显示AIRP的必要事实仍为1,300/1,300。模型对长列表进行校验和、平方和等计算时，即使输入包含全部数字，也可能计算错误。因此答案准确率应作为端到端任务质量指标单独报告，不能反推插件丢失了多少信息。

0%是当前显式指标下的观测结果，不是普遍的零损失保证。此审计只覆盖可枚举的函数表达式和默认值，没有覆盖隐式控制流、运行时反射、动态分派、跨进程状态、注释意图或真实缺陷修复。要声称普适低损失，需要在真实仓库中为每类任务建立人工标注的必要证据集合，再计算召回率与错误证据率。
